# GÖLGEYE CEZA KESEN BELEDİYE

> “Işık varsa gölge vardır. Gölge varsa tutanak vardır.”  
> — Hayalî Belediye Başkanlığı, 3. Olağanüstü Gölge Meclisi Kararı

Bu depo, kaldırımda izinsiz uzayan **gölgelere** idari para cezası kesen çok ciddi, çok resmi ve biraz da üşütük bir yazılımdır.

## Neden?

Çünkü:
- Gölgeler yürürken izin almıyor.
- Gölgeler vergi vermiyor.
- Gölgeler seçim bildirgesi okumuyor.
- Gölgeler “ben sadece duruyorum” diyor ama yer kaplıyor.

Bilim insanları (yani ben) yıllarca çalıştı. Sonuç: bir Python dosyası.

## Kurulum

```bash
git clone https://github.com/Tentivory/golgeye-ceza-kesen-belediye.git
cd golgeye-ceza-kesen-belediye
python3 golge_ceza.py
```

Python 3 yeter. Ek paket yok. Gölge zaten yeterince ağır.

## Kullanım

1. Adınızı yazın.
2. Gölgenizin yerdeki boyunu metre cinsinden girin (akşamüstü abartmayın).
3. Tutanak ekrana düşer.
4. Ödeme yapmayın. Zaten ödeme yeri kapalı.

Örnek çıktı:

```
Tutanak No     : GB-742011
Suçun Türü     : İzinsiz gölge uzatma
İdari para cezası: 73.64 TL
```

## Sık Sorulan Sorular

**Gölgem itiraz ederse?**  
Güneşe dilekçe yazın. Mesai saatleri: doğuştan batışa.

**Gece çalışır mı?**  
Gece gölge yoktur, sistem uyur. Bu bir özelliktir.

**Bu gerçek bir ceza mı?**  
Hayır. Gölgeniz özgürdür. Siz de özgürsünüz. Yazılım şaka yapıyor, zabıta değil.
